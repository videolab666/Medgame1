# «Мильна Хвиля» — дизайн-спецификация (MVP)

> Версия: 1.0 · Дата: 18.10.2026 · Статус: согласовано в брейншторме, ждёт ревью спеки
> Язык документа — русский; **все игровые тексты — украинские**.
> Проект — личная инициатива автора; демо/питч для КНП «Регіональний медичний центр
> родинного здоров'я» (м. Дніпро). Логотип и название больницы в игре **не используем**
> до письменного согласия администрации.

---

## 1. Кратко

| Параметр | Значение |
|---|---|
| Жанр | Свайп-аркада (механика Fruit Ninja), один палец |
| Действие | Не «резать», а **мыть**: мыльный след пальца ловит микробов в пузыри; фрукты режутся на витамины; свои клетки трогать нельзя |
| Аудитория | Основная 5–9 лет; играют на телефонах родителей в больнице |
| Доставка | QR-код в отделениях → URL на GitHub Pages → PWA, офлайн после первого открытия |
| Цели | Ребёнок залипает (сочность, коллекция) · мама одобряет (польза, нет рекламы/данных, точки остановки) · снижение тревоги (режим «Перед процедурою») |
| Платформа | Мобильный браузер (Chrome Android, Safari iOS), вертикальная ориентация основная |

## 2. Контекст и ограничения (из анализа больницы)

Источники: rmcrz.com, rmcrz.com/statti/dytyacha-medycyna/, UNICEF Ukraine
«Hospital lights never go out». Крупнейшая детская больница востока и юга Украины,
>400 тыс. детей/год, много пациентов из прифронтовых регионов; есть детская
онкогематология, ожоговое отделение (комбустиология), реанимация, отделение для
детей и подростков с расстройствами психики и поведения.

Обязательные правила дизайна (не обсуждаются при балансировке «сочности»):

| # | Правило | Причина |
|---|---|---|
| R1 | Нет взрывов, «БУМ», тряски экрана, военной лексики («бій», «ворог», «оборона», «армія») | Дети с травмой войны |
| R2 | Нет звуков, похожих на сирену; нет резких громких пиков; громкость по умолчанию низкая | То же |
| R3 | Нет полноэкранных вспышек чаще 1 раза в 400 мс (WCAG 2.3.1: ≤3 вспышки/с) | Риск фотосенситивной эпилепсии, неврология |
| R4 | Нет огня, жара, лезвий, звука ножа | Ожоговое отделение, предоперационные дети |
| R5 | Микробы смешные и глупые, не мерзкие и не злые (нет слизи, зубов, злобных лиц). Посыл — «я вмію впоратися», не «мікроби страшні» | Онкогематология: иммуносупрессия, тревога |
| R6 | Нет Game Over, жизней, проигрыша; раунд всегда заканчивается наградой | Ребёнок в стрессе |
| R7 | Нет стриков, ежедневных наказаний, FOMO, бесконечного раунда; есть точка остановки | Психиатрическое отделение; одобрение родителей |
| R8 | Нет рекламы, покупок, регистрации, трекеров, сторонних cookie, сетевых запросов после загрузки | Дети, гос. учреждение |
| R9 | Каждый медицинский факт имеет источник и статус проверки; до публикации в больнице — проверка врачом | Достоверность |
| R10 | Крупные цели (≈15% ширины экрана), хитбокс больше картинки, играбельно любой рукой лёжа | Катетер в руке, ослабленная моторика |
| R11 | Весь арт — оригинальный; без стиля конкретных студий (Pixar/Disney), без ассетов с неясной лицензией | Лицензионная чистота питча |

## 3. Игровой цикл

### 3.1 Раунд (режим «Грати»)
- Длительность 60 с. Объекты вылетают снизу по баллистическим дугам.
- Плотность: 0–10 с — до 2–3 объектов на экране; к 60 с — до 6–7 (кривая в `config.js`).
- Свайп засчитывается, если скорость пальца ≥ порога (`SWIPE_MIN_SPEED`); иначе след
  рисуется тусклым и не «моет».

| Объект | Действие при свайпе | Очки/эффект |
|---|---|---|
| Микроб | Попадает в мыльный пузырь, удивлённо моргает, всплывает, лопается конфетти | +1, комбо +1, нота ксилофона |
| Фрукт | Режется на 2 половинки по линии свайпа, брызги сока, светящаяся капля-витамин летит в «баночку здоров'я» | +1 витамин, комбо +1 |
| Своя клетка | Хихикает «лоскотно!», отлетает в сторону | Комбо сбрасывается. Жизни не отнимаются |
| Бонус «Мило» | Мыльная волна снизу вверх очищает экран от микробов | Все микробы на экране засчитаны |
| Бонус «Щеплення» | Сияющий щит-купол в центре экрана на 5 с: любой микроб, коснувшийся купола, сам попадает в пузырь (засчитывается) | Учит: прививка = защита |
| Бонус «Латочка» | Всё замедляется на 4 с | Учит: тромбоциты «латают» |

- Комбо-пороги: 3, 5, 10 подряд → всплывающая надпись «×3!/×5!/×10!» (squash & stretch),
  след пальца становится радужнее, ноты выше.
- Конец раунда: экран награды — наклейка (новая или дубль → «+звёздочка» к наклейке),
  один факт (≤ 12 слов), кнопки «Ще раз» / «До меню».
- Каждые 3 раунда подряд — экран «Чудова робота! Перепочинь» с персонажами; кнопка
  «Ще раз» доступна сразу (не блокируем, но предлагаем паузу).

### 3.2 Режим «Перед процедурою»
- Без таймера, очков и комбо. Пузыри с микробами медленно всплывают; касание или свайп
  мягко их лопает.
- Круг дыхания «Надуй кульку»: вдох 4 с (круг растёт), выдох 4 с (сжимается);
  пузыри всплывают в такт.
- Музыка тише и медленнее. Выход в меню в любой момент.

### 3.3 Туториал
Первый запуск — первый раунд в «Долоньках» содержит призрачную руку, показывающую свайп,
и одну клетку с подсказкой-иконкой «не чіпай». Без текстовых инструкций.

## 4. Контент MVP

### 4.1 Локации (3)
| Локация | Фон | Состав спавна | Тема фактов |
|---|---|---|---|
| «Долоньки» | Мыльный мир: пена, пузыри, плитка | В основном микробы, мало фруктов | Миття рук |
| «Кухня вітамінів» | Тёплая кухня, солнце в окне | Больше фруктов | Харчування, вітаміни |
| «Річка крові» | Пастельно-розовая река, без крови и органов | Микробы + много своих клеток | Клітини крові |

Открытие: «Долоньки» с начала; следующая локация — после 3 раундов в предыдущей.
Каждая локация — 8 наклеек; всего 24. Наклейка выпадает из ещё не собранных в локации.

### 4.2 Персонажи
Стиль «Glossy Candy» (раздел 6). Имена украинские.

- Микробы: **Чихунчик** (круглый, мягкие пупырышки, чихает), **Бруднюля** (палочка
  с усами), **Липучка** (клякса-желе), **Кашлюк** (квадратик, покашливает).
- Свои клетки: **Червоня** (эритроцит-«пончик» с рюкзаком пузырьков кислорода),
  **Білик** (лейкоцит в докторской шапочке; гид игры), **Латочка** (тромбоцит с пластырем).
- Фрукты/овощи: апельсин, яблоко, киви, клубника, брокколи.

### 4.3 Факты (`content/facts.uk.json`)
Схема записи:
```json
{
  "id": "fact.hands.01",
  "location": "hands",
  "text": "Мий руки з милом щонайменше 20 секунд!",
  "source": "CDC, Handwashing: Clean Hands Save Lives",
  "status": "draft"
}
```
- `status`: `draft` → `reviewed` (врач больницы). В MVP все `draft`; на экране «Для батьків»
  указано, что факты ожидают проверки врачом.
- Лимит текста: ≤ 12 слов, ≤ 80 символов.
- MVP: не меньше 8 фактов на локацию (24+). Ротация — без повторов, пока не показаны все
  факты локации.

Стартовый набор тем (формулировки финализируются при реализации, каждая с источником):
мытьё рук ≥ 20 с с мылом; мыло смывает микробов; руки моем перед едой и после туалета;
витамин C в апельсине, киви, брокколи; фрукты и овощи каждый день; вода полезна;
эритроциты переносят кислород; лейкоциты защищают от микробов; тромбоциты помогают
закрыть ранку; прививка учит организм защищаться.

### 4.4 Озвучка
В MVP нет. Каждая фраза имеет id; `audio/voice.js` вызывает `playVoice(id)`: если файл
`public/voice/<id>.mp3` существует — играет, иначе тишина. Позже — живой голос
(запись 40–60 фраз по сценарию) без изменений кода. На экране награды для младших —
подсказка «Прочитайте дитині».

## 5. Экраны (DOM-оверлей поверх canvas)
1. **Старт:** «Грати» (локация — последняя открытая, выбор свайпом карточек), «Перед
   процедурою», «Атлас», переключатель звука (крупная кнопка).
2. **Раунд:** canvas + HUD (таймер-кольцо, счётчик витаминов, пауза).
3. **Награда:** наклейка, факт, «Ще раз», «До меню».
4. **Перепочинь:** раз в 3 раунда.
5. **Атлас тіла:** сетка 3×8 наклеек по локациям; тап по наклейке — карточка персонажа
   с фактом.
6. **Для батьків:** о игре, правила приватности (никаких данных), статус фактов,
   «прогрес зберігається лише на цьому телефоні», кнопка сброса прогресса.

## 6. Визуальный стиль и эффекты

### 6.1 Стиль «Glossy Candy»
- Персонажи — оригинальные SVG, собранные из частей (тело, глаза, рот, аксессуар) для
  независимой анимации: моргание, покачивание, squash & stretch.
- Рендер: градиентная заливка, глянцевый блик слева сверху, rim-light, мягкий контур
  темнее основного цвета (не чёрный), большие глаза с двумя бликами, румянец.
- Палитра: фон мятный `#ebfaf2` → небесный; UI-акцент `#dd2590`; текст `#1f5063`;
  вторичный `#217b9e`; персонажи — насыщенные конфетные цвета.
- Фоны пастельные, абстрактные, с параллаксом, боке и плавающими силуэтами.

### 6.2 Эффекты («сочность»)
- Частицы: sparkle (блёстки), confetti, juice (сок), bubblePop, starRain (финал).
- След пальца: `MeshRope` с радужной текстурой, сужается к хвосту; насыщенность растёт с комбо.
- Bloom (`AdvancedBloomFilter`) только на fx-слое; `GodrayFilter` на фоне; `GlowFilter`
  на бонусах.
- GSAP: появление объектов (overshoot), всплывающие надписи комбо (elastic), падение
  наклейки (bounce), кнопки (press squash).
- Все полноэкранные изменения яркости проходят через `flashGuard` (≤ 1 раз / 400 мс).

### 6.3 Звук (процедурный WebAudio)
- Ксилофон в пентатонике: каждое попадание — следующая нота, высота растёт с комбо
  (любая цепочка звучит гармонично).
- pop пузыря, хихиканье клетки (глиссандо вверх), мягкий фоновый эмбиент (pad + арпеджио).
- Звук включается после первого касания; громкость по умолчанию 40%; mute сохраняется.

## 7. Архитектура

### 7.1 Стек
Vite · PixiJS v8 · GSAP (бесплатный с 2025, вкл. плагины) · `pixi-filters` v6 ·
`vite-plugin-pwa`. Все зависимости бандлятся локально (без CDN). Хостинг — GitHub Pages
(GitHub Actions workflow).

### 7.2 Модули
```
src/
  core/        чистый JS, без Pixi/DOM — тестируется в Node
    config.js    константы баланса
    rng.js       seeded RNG (mulberry32)
    spawner.js   расписание спавна, рост сложности, правило честности
    physics.js   баллистика, вращение, выход за экран
    swipe.js     буфер точек, скорость, пересечение отрезок–круг
    round.js     RoundState + события: hit, cellTouched, combo, bonus, end
    progress.js  наклейки, открытие локаций; storage-адаптер внедряется
    content.js   выбор фактов с ротацией
  render/
    stage.js     Pixi Application, resize, DPR ≤ 2, слои bg/entities/fx/hud
    art/         SVG-части персонажей → текстуры
    entity.js    Container персонажа из частей + idle-анимации
    quality.js   выбор уровня по FPS первых 2 с
  fx/
    particles.js  свой эмиттер на ParticleContainer, пул, пресеты
    trail.js      радужный MeshRope
    capture.js    микроб → пузырь → всплытие → конфетти
    slice.js      фрукт → 2 половинки по маске линии свайпа
    post.js       bloom/godray/glow по уровню качества
    flashGuard.js ограничитель полноэкранной яркости
  audio/
    synth.js     процедурный звук
    voice.js     слот под живой голос
  ui/            DOM-экраны (раздел 5), GSAP-анимации
  main.js        машина состояний: Title → Round → Reward → (Rest) → Title | Calm | Atlas | Parents
content/facts.uk.json
ART_LICENSE.json
```

### 7.3 Поток данных
Pointer events → `swipe` (сегменты за кадр) → `round.update(dt, segments)` фиксированным
шагом 1/60 с → события → подписчики `fx`, `audio`, `hud`, `progress`. Рендер интерполирует
и может пропускать кадры; логика детерминирована при заданном seed.

### 7.4 Уровни качества
| Уровень | Bloom | Godray | Макс. частиц |
|---|---|---|---|
| High | полный | да | 2000 |
| Mid | ½ разрешения | нет | 800 |
| Low | нет | нет | 300 |
Старт с High; если средний FPS первых 2 с < 50 → Mid; < 35 → Low.

### 7.5 Ошибки и края
- Нет WebGL/WebGPU → экран «Відкрийте гру в Chrome або Safari».
- `AudioContext` создаётся/возобновляется по первому касанию.
- `visibilitychange` → пауза раунда; возврат — экран паузы с «Продовжити».
- `localStorage` недоступен → прогресс в памяти, без ошибок.
- Ориентация: раскладка от короткой стороны; горизонталь играбельна.

### 7.6 Бюджеты
- Начальная загрузка < 600 КБ gzip.
- ≥ 45 FPS на уровне Mid при 4× CPU throttling в Chrome DevTools-эмуляции 390×844.

## 8. Тестирование
- `node --test` для `core/`: пересечение свайпа и порог скорости; клетка сбрасывает комбо
  без потерь; бонусы и их длительности; раунд всегда завершается событием `end` с наградой;
  открытие локаций; выдача наклеек без дублей пока есть несобранные; ротация фактов;
  детерминизм спавна по seed.
- Валидаторы (`npm run validate`): факты (id уникален, лимит длины, источник, статус);
  арт (каждый SVG в `ART_LICENSE.json` с `origin: "original"`); запрещённые слова R1 в
  `facts.uk.json` и UI-строках.
- Playwright smoke: 390×844, 4× CPU throttle; Play → скриптовый свайп → экран награды;
  0 ошибок консоли; замер FPS; скриншоты.
- Ручная проверка на реальном телефоне по LAN.

## 9. Вне MVP (позже)
Живая озвучка; выбор аватара ребёнка (в т.ч. без волос, в очках, на коляске); новые
локации («Ротик», «Животик», «Шкіра»); режим для подростков; согласование брендинга с
больницей; иллюстрации для питча (локальная генерация Flux/SDXL с записью лицензии).

## 10. Изменения после MVP (18.10.2026)
- **Локации 4–6:** «Ротик» (зубы; свой — Зубчик, бонус «Щіточка» = мыльная волна), «Животик» (свой — Добрик, полезная бактерия: учим, что не все микробы плохие), «Шкіра» (уход за кожей, пластырь, солнце). Открываются цепочкой по 3 раунда. Пулы объектов — `LOCATION_TYPES` в `src/core/config.js`; бонусы → эффекты через `BONUS_EFFECT`.
- **Контент:** +24 факта (draft, с источниками), +10 оригинальных SVG, 48 наклеек.
- **Аудио:** записанные треки/эффекты подхватываются из `public/music`, `public/sfx` по `index.json`; иначе — процедурный звук. Промпты Suno — `docs/music/suno-prompts.md`; лицензии — `AUDIO_LICENSE.json` (проверяется валидатором). Аудио кэшируется service worker'ом при первом проигрывании, не в precache.
- **Прочее:** вибрация (Android, выключается вместе со звуком), счётчик микробов в HUD, масштаб мира по короткой стороне экрана (горизонталь).
