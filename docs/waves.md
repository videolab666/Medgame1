# Мильна Хвиля: стадии, паузы и количество объектов

> Сгенерировано из `src/core/waves.js` — не редактировать вручную.
> Обновить после правок плана: `npm run waves` (или `node scripts/waves-table.mjs`).

Точный разбор всего, что вылетает в игре: стадии по порядку, паузы до сотых секунды,
количество объектов на каждой стадии, сколько всего вылетает за раунд, какие виды
объектов даёт каждая локация — и как один длинный забег продолжается от раунда к раунду.

## Как устроена стадия

- **Стадия** — один слот плана `WAVE_PLAN`. Раунд начинает не с первой стадии, а с той,
  на которой остановился прошлый раунд этой локации (первый раунд — с начала); когда
  список из 23 стадий кончается, повторяется последняя (набор E) — до конца забега.
- Стадия начинается с паузы **«перед»** (живой `m_startDelay`): стадии 1–5 — 1 с, стадии 6 и дальше — 0.8 с.
- Затем вылетают серии: все группы серии начинаются одновременно, внутри группы
  объекты идут друг за другом каждые **gap** секунд (0 — все вместе): 0.7 / 0.6 / 0.5 / 0.4 / 0.3 / 0.25 с.
- Паузы **«после»** нет. Следующая стадия начинается, когда **все объекты прошлой исчезли**
  (разрезаны, пойманы или упали за экран), и ждёт только свою «перед». Так ведёт себя
  эталонная игра (замер по видео: ~1 с от исчезновения фрукта до следующего броска).
  Кто режет быстрее — получает следующие серии раньше.
- Количество объектов `n` — диапазон `мин–макс` включительно; строка «Разброс» — время
  от первого до последнего объекта серии.
- Группа бывает трёх видов: обычные бросания (микробы и фрукты), `kind: 'cell'` — только
  «свои» персонажи, которых нельзя трогать, и шаблон `seq`: «s» — обычное бросание,
  «c» — «свой» (например, «ssc» — два объекта, затем персонаж). Всё, что вылетает за
  концом шаблона, — обычные объекты.
- Варианты в наборах A–E выбираются случайно по весу, но только что выпавший вариант
  получает вес 0 и сразу выпасть не может; после каждого выбора всем вариантам
  начисляется +33 % базового веса (не выше базового). В наборах из двух
  вариантов (A и D) из-за этого варианты строго чередуются. Веса переживают границу
  раунда: следующий раунд продолжает «отрастание» с того же места.
- Время в игре идёт по кадрам (1/60 с), поэтому вылет может отличаться от табличного
  не больше чем на кадр.

## Паузы

| Перерыв | Значение |
|---|---|
| От начала раунда до первого объекта | 0.5 с |
| «Перед» серией (живой `m_startDelay`) | стадии 1–5 — 1 с, стадии 6 и дальше — 0.8 с |
| Между объектами внутри серии | 0.7 / 0.6 / 0.5 / 0.4 / 0.3 / 0.25 с или все вместе (gap 0) |
| Серия целиком | 0–6 с (зависит от количества объектов) |
| «После» серии (у всех стадий) | нет паузы (0 с — как в живой партии) |
| От исчезновения последнего объекта серии до первого объекта следующей стадии | «перед»: 1 с (1→2 … 4→5), 0.8 с (5→6 и дальше) |
| Новые стадии | не начинаются в последние 1.5 с раунда |
| Новые объекты | не вылетают позже чем за 0.4 с до конца раунда |

Раунд: первая игра в локации — 40 с, каждая пройденная добавляет
5 с, максимум 60 с (по числу игр: 40, 45, 50, 55, 60, 60…).

## Прогрессия забега по раундам

Сложность растёт от раунда к раунду: каждый раунд продолжает список стадий с того места,
где остановился прошлый (как одна непрерывная классическая партия). Курсор стадии,
накопленная скорость набора E
и «отрастающие» веса хранятся в сохранении на каждую локацию.

По 300 случайным сидам, раунды идут подряд с растущей длительностью:

| Раунд | Длительность | Стартовая стадия |
|---|---|---|
| 1 | 40 с | 1–1 |
| 2 | 45 с | 10–11 |
| 3 | 50 с | 18–22 |
| 4 | 55 с | 23–23 |
| 5 | 60 с | 23–23 |
| 6 | 60 с | 23–23 |

Повторяющийся набор E начинается с раунда 4 (у 300 из 300 сидов).
Дальше каждый вариант набора E ускоряется на 0.02 за каждое использование (до ×1.5) — как
у последних волн классической партии: чем больше раундов, тем быстрее полёт в этом наборе.

## «Свои» персонажи и жизни

Жизни и досрочный конец раунда включаются флагом `CONFIG.GAME_OVER` (сейчас: включены).
Проигрыша нет (R6): досрочный конец — тот же экран награды. Без флага раунд идёт до конца времени.

- «Свои» (персонажи, которых нельзя трогать) вылетают только по расписанию плана:
  случайно встретить их нельзя. Стадия 5 — урок: 1–2 персонажа одни, полёт замедлен.
- Касание персонажа: без флага — персонаж хихикает, комбо сбрасывается; с флагом — раунд
  завершается сразу, ребёнок видит обычный экран награды и доброе слово.
- Жизни (только с флагом): 3 сердечка. Промах (объект улетел несрезанным) отнимает одно;
  первое возвращается на 100 очках, дальше каждые 100.
  Очки — это и микробы, и витамины.
- Когда сердечки кончились, раунд завершается досрочно — так же по-доброму.

## Король микробов

- Появляется на 50 очках, затем каждые 100.
- Большой (×1.35), летит сбоку; пока он на экране, время замедлено до 35 %,
  очередь стадий ждёт, а «свои» разлетаются в стороны.
- Каждый разрез даёт очко, но не чаще чем раз в 0.08 с. Первый разрез
  «обезвреживает» всех «своих» на экране: их уже можно трогать — они просто лопаются.
- Через 5 с король лопается: за 1.2 с время разгоняется с 5 % до 100 %.
- Камера приближается (×1.12) и слегка тянется к каждому разрезу.

## Виды объектов по локациям

| Локация | Микробы | Фрукты | «Свои» этой локации |
|---|---|---|---|
| Долоньки | 82 % | 18 % | Червоня, Білик, Латочка |
| Кухня вітамінів | 41 % | 59 % | Червоня, Білик, Латочка |
| Клітинкова річка | 75 % | 25 % | Червоня, Білик, Латочка |
| Ротик | 69 % | 31 % | Зубчик |
| Животик | 64 % | 36 % | Добрик |
| Шкіра | 73 % | 27 % | Латочка, Білик |

Доли — вероятность микроба/фрукта для каждого обычного бросания. «Свои» вылетают
по общему расписанию (одинаковому во всех локациях) — меняются только их лица.
В стадиях 1–2 (первые 2 слота) персонажей и бонусов не бывает — только микробы и фрукты.
Бонусы: шанс 6 % на объект, не больше 3 за раунд,
влетают сбоку, на уровне ниже обычных бросков.

Спокойный режим (меню и «Перед процедурою») — без стадий: редкие плавающие микробы,
не больше шести на экране.
